# Tawakkal — Personal Portfolio

A single-page personal portfolio based on the approved Google Stitch desktop and mobile designs.

## Stack

- HTML5
- Tailwind CSS v4 (CLI)
- Custom CSS for the scrapbook/editorial details
- Vanilla JavaScript (ES modules)
- No backend, database, React, or Next.js required

## Requirements

- Node.js 20 or newer
- npm

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:5500` if it does not open automatically. The development command runs the Tailwind watcher and a local static server.

## Production build

```bash
npm run build
npm run preview
```

The production-ready static site is generated in `dist/`.

## Design references

Original Google Stitch screenshots and the PRD / design specification are retained in `design-references/` and `docs/` for visual QA.
